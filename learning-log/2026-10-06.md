## 📚 今日学习内容

### 1. TRAE

理解 TRAE 是用于编写、管理和运行代码的开发工具。

### 2. Terminal

理解 Terminal 是直接向电脑发送命令的环境。

3. Python Virtual Environment
使用：python -m venv .venv创建项目独立的 Python 虚拟环境。
理解 .venv 的作用是让不同项目拥有相对独立的 Python 环境和依赖。

4. pip
理解 pip 是 Python 的包管理工具，可以安装第三方 Python 库。
例如：python -m pip install requests

5. API
通过 HTTP 请求测试 API，并成功获得 HTTP 200。
初步理解 API 是不同软件或服务之间进行通信的一种接口。

6. API Key
理解 API Key 是访问部分 API 服务时使用的身份凭证。
7. .env 和环境变量
使用 .env 保存 API Key：AI_API_KEY=...
Python 通过：os.getenv("AI_API_KEY")读取环境变量。
没有直接把真实 API Key 写进 Python 代码。
8. Terminal Environment Injection
遇到了 API Key 无法通过环境变量读取的问题。
TRAE 提示：
An environment file is configured but terminal environment injection is disabled.
随后启用：python.terminal.useEnvFile重新加载环境后，Python 成功读取 API Key。
最终测试结果：读取结果： True
API Key 已成功读取！
